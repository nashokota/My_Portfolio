# My Portfolio Website  

This is my personal portfolio website built with **ASP.NET Web Forms**.  
It showcases my background, skills, projects, and includes a contact form.  

## Features  
- About Me section  
- Skills section (with admin panel to manage skills)  
- Projects showcase  
- Contact form 
- Responsive design 

## Tech Stack  
- ASP.NET Web Forms (C#)  
- HTML, CSS, JavaScript  
- MySQL (for skills and project data)
